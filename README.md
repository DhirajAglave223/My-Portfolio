## 🌟 Overview

Welcome to my personal 3D interactive portfolio website. Built with cutting-edge web technologies, it features smooth 3D space backgrounds, custom cursor interactions, Lenis smooth scrolling, and dynamic responsive layouts.

## 🛠️ Tech Stack

- **Frontend:** React 19, Vite, HTML5, Modern CSS
- **3D & Visuals:** Three.js, React Three Fiber (`@react-three/fiber`), Drei (`@react-three/drei`)
- **Animations:** Motion (`motion/react`), Lenis Smooth Scroll
- **Icons:** Lucide React, React Icons

## 🚀 Features

- 🌌 **Global 3D Space Scene** — Interactive 3D celestial background spanning the entire experience
- ⚡ **Smooth Performance** — Fast page loads powered by Vite and React 19
- 🎨 **Glassmorphism & Neon UI** — Sleek dark-mode aesthetic with custom animations
- 📱 **Fully Responsive** — Optimized for desktops, tablets, and mobile devices
- 🎯 **Interactive Sections** — Hero, About, Skills, Education, Projects, AI Showcase, and Contact

## 💻 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/DhirajAglave223/My-Portfolio.git
   cd My-Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
